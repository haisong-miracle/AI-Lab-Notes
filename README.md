## 提交规范

本仓库遵循 [Conventional Commits](https://www.conventionalcommits.org/zh-hans/)：

| 前缀 | 含义 | 示例 |
| :--- | :--- | :--- |
| `feat` | 新增内容或功能 | `feat(notes): 新增 Git 速查表` |
| `fix` | 修正错误 | `fix(docs): 修正图片引用路径` |
| `docs` | 文档变更 | `docs: 补充环境配置说明` |
| `chore` | 杂项（配置、忽略文件） | `chore: 初始化仓库结构` |

## 分支约定

- `main`：稳定分支，只接受通过分支合并的变更
- `feature/<主题>`：功能分支，开发完成后合并回 `main`
